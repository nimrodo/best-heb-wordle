## Agent skills

### Issue tracker

Issues live in GitHub Issues at nimrodo/best-heb-wordle, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Shell, merging, reviews and browser checks

Review standards: `CODING_STANDARDS.md`. Driving the UI in a browser: `docs/agents/browser-checks.md`. Shell gotchas (macOS `sed -i`) and merging (delete the branch): `docs/agents/shell-and-merge.md`.
